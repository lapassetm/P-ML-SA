# Portfolio Web - Maite Lapasset

Este paquete contiene la estructura completa del portfolio web para Maite Lapasset.

## Estructura de la carpeta:
```
portfolio/
│
├── index.html         # Archivo principal de la página HTML
├── README.txt         # Instrucciones de uso
└── css/
    └── styles.css     # Hoja de estilos CSS pura con variables y Flexbox
```

## Cómo usarlo:
1. Descomprimir el archivo ZIP.
2. Hacer doble clic en `index.html` para abrir la página web directamente en cualquier navegador (Chrome, Edge, Safari, Firefox).
3. Para editar datos o estilos, se pueden abrir los archivos `index.html` o `css/styles.css` con cualquier editor de código (como Visual Studio Code o el NotePad/Blog de notas).
